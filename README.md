# Қазақстан картасындағы Менделеев кестесі

Интерактивті 3D оқу құралы: Қазақстанның 3D картасы, кен орындарына виртуалды саяхат, 118 элементтен тұратын 3D Менделеев кестесі, виртуалды химия зертханасы және викторина. Барлық мәтін мен дыбыстау — қазақ тілінде.

**Авторы:** Маулен Айдана, «Васильковка негізгі мектебі» КММ
**Байқау:** «Педагогикалық идеялар фестивалі», «Шеберлік палитрасы» бағыты

## Іске қосу

`index.html` файлын браузерде ашыңыз. Сайт интернетсіз де жұмыс істейді.

Тікелей сілтемелер: `index.html#map`, `#table`, `#lab`, `#el=Cu`, `#dep=aktogay`, `#rx=volcano`.

## Мүмкіндіктер

- **3D карта** — 28 кен орны, айналып тұрған элемент текшелері, қалалар, өзендер мен көлдер.
- **Кен орнына саяхат** — карьер, шахта, жерасты шаймалау, мұнай кәсіпшілігі, теңіз аралы, тұзды көл, зауыттың 3D модельдері.
- **Менделеев кестесі** — 118 элемент, 4 көрініс, атомның 3D моделі, нақты фотосуреттер.
- **Зертхана** — 14 анимациялық тәжірибе.
- **Викторина**, **авто-тур** (дауыстық саяхат), домбыра әуені.
